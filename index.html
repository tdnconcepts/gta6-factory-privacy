## Data accessed and purpose
The fixed pilot reads a publisher-advertised GTA6 Scoop RSS feed and public
YouTube Data API v3 channel/video metadata. It checks a channel handle against
an expected ID, then requests one page of at most 20 video references.
Selected fields include public titles, original source URLs, publication dates,
author/channel names and provider IDs. Local provenance includes request and
retrieval times, first observation, response hashes, errors and request/byte
accounting. RSS may contain article text or image references in the received
body; these are ignored and no linked article, image or media is fetched.
The purpose is to evaluate whether references can support later independent
GTA editorial research. Live data stays unranked, factually unverified and
separate from synthetic Viral Radar scoring. No popularity, trend velocity,
creator performance, user profiling or content categories are inferred.
No creator script, image, audio or video may be reproduced under this notice.

## Credentials, network and sharing
There is no OAuth, YouTube login/password collection, private account access,
write/upload operation or embedded player. A dedicated API key is read only
from the local process environment after this notice is accepted and approval
checks pass. It is transmitted to Google's approved API host in an HTTPS
request header, never intentionally to the RSS publisher, files or logs.
Google receives the API requests, project/key identification and connection
information such as the public IP address; the RSS publisher receives its
request and connection information. Their processing is governed by their own
policies. There are no tracking cookies, advertising, analytics beacons,
automatic browser opens, remote scripts, image/video downloads or background
collection. Local files are accessible to the two designated operators and
people/processes with access to the Windows account or backups; protect those
files and keep them out of shared or synced locations. No API data is sent to
Factory production, external AI services or other recipients by this client.

## Local storage and retention
Response bodies are processed in memory only, not deliberately written to
disk. Process exit does not guarantee secure erasure of RAM, swap or OS dumps.
Selected metadata, evaluation files, request logs, errors and supervision data
are kept in a dedicated local pilot-data folder for at most 72 hours from pilot
start, including any copies or exports.
Approval/retention manifests and the acceptance receipt are retained for at
most seven days (168 hours) from approval issuance. The acceptance receipt
records only operator identity, acceptance time and policy version/hash.
It does not record input text, device identifiers or credentials.
The designated retention and deletion owner must delete artifacts within those
limits; there is no automatic deletion scheduler or automatic data refresh.
A source-data-free empty directory remains to prevent accidental run replay.
This owner/contact configuration is separate from collected API data and is
maintained while the client and its published notice remain in use.

## Deletion, questions and withdrawal
Either operator can contact the client owner above for privacy questions,
withdraw further use, or request earlier deletion of local pilot data.
The owner must act promptly and no later than the existing retention deadlines
(or seven days for a user deletion request, whichever is earlier), including
copies/backups. Contact gta6factory.contact@gmail.com to request deletion or
ask how to inspect and remove local pilot files. Approval records must also be
removed by their seven-day deadline. These operations
never delete data on YouTube or change Factory production data.
No OAuth access exists to revoke. The project owner can revoke the API key in
Google Cloud and remove it from the PowerShell session. API-key revocation is
separate from deletion of retained local files.
